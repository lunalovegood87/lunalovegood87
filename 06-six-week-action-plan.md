# 06 — Six-Week Action Plan

Designed for **≤5 hrs/week**, **no social media**, **no public profile required**. The goal by end of week 6 is not "money in the bank" (that depends on client cycles) but a **live pipeline**: assets ready, the legal path decided, and 20–30 well-targeted contacts made with at least one call booked. First payment typically lands in weeks 6–12; the expert-network line (week 1) can be faster.

Check boxes as you go. Each week is ~4 hours. Do **Week 0 first — it's the one real blocker.**

## Week 2 — Decide the legal path + build the target list
- [ ] Have the SMMM call. Decide: *şahıs şirketi / serbest meslek* now, or later. Get the monthly bookkeeping cost.
- [ ] Build a **target list of 25 named organizations/people** across the three services (a simple spreadsheet: name, org, why them, which service, email). Sources: recent Horizon Europe/Interreg project pages, consultancy "our team" pages, papers in your area, TÜBİTAK/EU project databases, your own network.
- [ ] Tag which 8 are **warm** (someone you or a colleague could introduce you to). Warm contacts convert far better — start there.

## Week 3 — First outreach wave (warm + best cold)
- [ ] Personalise and send **Service-1 and Service-2 emails to your 8 warm contacts** (`04-...`). One recipient, one researched reason each. ~20 min per email.
- [ ] Send **5 cold** emails to the best-researched names on the list.
- [ ] Log every send in your spreadsheet with the date (so you know when to follow up).
- [ ] If any expert-network calls come in, take them. That's real income already.

## Week 4 — Second wave + first calls
- [ ] Send the **one follow-up** to Week-3 non-repliers (template in `04-...`). Then stop chasing them.
- [ ] Send **8 new** outreach emails (mix of services, prioritise Service 3 to consortium coordinators).
- [ ] Run any **scoping calls** that get booked. After each: send a short written scope + quote from `05-...` within 24 hours.
- [ ] Note objections you hear — they tell you what to adjust.

## Week 5 — Convert + refine
- [ ] Turn scoping calls into **written quotes/proposals** (package price, deliverables, timeline, 40–50% upfront).
- [ ] Send **8 more** outreach emails, doubling down on whichever service is getting the most traction.
- [ ] If you've landed a first project: agree terms, take the deposit, schedule the work into a batched block.
- [ ] Optional: draft a one-page static services page (only if you decided it's acceptable) — no blog, no feed, just a page an email can link to.

## Week 6 — Consolidate + set the rhythm
- [ ] Review the funnel: emails sent → replies → calls → quotes → wins. Which service pulls? Which message worked?
- [ ] **Finalize the legal setup** if income is now real (register, or line it up so you can invoice on demand).
- [ ] Deliver / progress any live work. Ask satisfied clients for **an introduction, not a testimonial** (referrals are your no-social-media growth engine).
- [ ] Set a **standing rhythm**: ~5 targeted outreach emails/week + take inbound calls. That's the whole ongoing motion.

## What "done" looks like at week 6
- Legal/invoicing path decided (and outside-work question answered).
- Bilingual assets ready to send in minutes.
- 25+ contacts made, one follow-up cycle complete, ≥1 call held.
- Expert-network profiles live (if opted in) — possibly first income.
- A repeatable weekly habit that fits under 5 hours.

## If a week gets eaten by academic work
Do only the **one highest-leverage task**: send 3 personalised warm emails. Pipeline decays without new contacts; everything else can wait a week.
